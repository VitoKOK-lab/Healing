# 寶石實拍圖

把去背後的寶石照片放在這個資料夾,然後到 `../gem-data.js` 的
`FAMILIES` 裡,幫那一顆加上 `img` 欄位:

```js
{ name: "紫水晶", img: "amethyst.png", color: "#b98fdc", accent: "#7d4fae", ... }
```

## 規格
- **格式**:PNG,去背(透明底)
- **尺寸**:正方形,400×400 以上(頁面上最大顯示 96px,報告圖上更大)
- **檔名**:英文小寫,對應石頭即可,例如 `amethyst.png`、`rose-quartz.png`
- **檔案大小**:單顆建議 100KB 以內

## 沒放圖會怎樣
自動用 `color` / `accent` 畫的漸層球代替,不會壞掉。
所以可以一顆一顆慢慢補,不必等全部到齊才上線。

## 授權提醒
這是營利用途。網路上多數「免費 PNG」站(HiClipart 明文禁止商用、
PNGTree/CleanPNG 來源不明)都不適合。最安全也最準確的做法是自己拍——
客人收到的實物才會跟推薦圖一致。
